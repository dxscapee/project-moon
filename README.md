# project-moon

Учебный проект: разработка программы для мягкой посадки на поверхность Луны.

Написано на C++ (стандарт C++20), сборка через CMake.

**Выполнили:** Студенты РИ-252701
**Руководитель:** Титаев А. А.

## Задача проекта

Смоделировать посадку космического аппарата на Луну: аппарат должен коснуться
поверхности с минимально возможной скоростью, имея ограниченный запас топлива.

На текущем этапе проекта модель сильно упрощена: рассматривается движение
с постоянным ускорением в одномерном случае (вверх/вниз), без учета гравитации
и расхода топлива. Это сделано намеренно: сначала нужно убедиться, что численные
методы работают правильно, и только потом усложнять физику.

## Ход работы по итерациям

### Итерация 1 — проверка численных методов (текущая)

**Задача итерации:**

Сравнить два численных метода интегрирования — Эйлера и Рунге-Кутты 4-го порядка (RK4) —
на задаче, для которой есть аналитическое решение, и по погрешности выбрать метод
для дальнейшей работы.

В качестве тестовой задачи взято движение с постоянным ускорением:

```
S(t) = S_0 + V_0 * t + a * t^2 / 2
V(t) = V_0 + a * t
```

Так как точное решение известно, погрешность каждого метода считается напрямую:

```
error = |S_num - S_exact| / S_exact * 100%
```
Если `S_exact = 0`, относительная погрешность по данной формуле не определена. В текущей реализации для этого случая используется условное значение 100%.

**Как реализовано:**

Весь расчет ведется в классе `imitation` (`imitation.h` / `imitation.cpp`).
Класс хранит начальные условия (S_0, V_0, a), текущее состояние (S_curr, V_curr)
и параметры интегрирования (t_curr, t_step, t_max). Для обоих методов сделаны
отдельные функции шага по времени:

- `euler_step()` — один шаг метода Эйлера
- `RK4()` — один шаг метода Рунге-Кутты 4-го порядка

В `main.cpp` создаются два объекта класса с одинаковыми начальными условиями,
далее в цикле по времени каждый объект делает свой шаг, а в конце результаты
сравниваются с аналитикой. Начальные условия зашиты в `main.cpp`:

```
S_0 = 0      начальная координата
V_0 = 0      начальная скорость
a   = 2      ускорение
шаг по времени = 0.01
t_max = 10
```

**Результаты:**
(прогон выполнялся на GCC-13, Linux, шаг 0.01)

| Метод         | S(t_max) | S точное | Погрешность |
| ------------- | -------- | -------- | ----------- |
| Эйлера        | 99.900   | 100.000  | 0.100%      |
| Рунге-Кутта 4 | 100.000   | 100.000  | 0.000%      |

## Сборка и запуск

Требуется: CMake версии 3.20 или выше и компилятор с поддержкой C++20:

- Windows — Visual Studio 2022 (Community) или MSVC Build Tools
- Linux / macOS — GCC или Clang

В `CMakeLists.txt` включены строгие предупреждения компилятора: для MSVC используются `/W4 /WX /permissive- /sdl`, для GCC и Clang — `-Wall -Wextra -Werror -Wpedantic`. Для конфигурации Debug отключена оптимизация и включена отладочная информация, для Release включена оптимизация.

### Linux / macOS

```bash
git clone https://github.com/dxscapee/project-moon.git
cd project-moon
cmake -B build
cmake --build build
./build/app
```

### Windows (Visual Studio)

Откройте папку проекта в Visual Studio 2022 (Файл → Открыть → Папка). Visual Studio обнаружит `CMakeLists.txt` и позволит собрать проект через меню «Сборка → Собрать все».

Также можно выполнить команды в Developer Command Prompt:

```bat
git clone https://github.com/dxscapee/project-moon.git
cd project-moon
cmake -B build
cmake --build build --config Release
.\build\Release\app.exe
```

Замечание: в MSVC тип `long double` имеет ту же точность, что и `double`, в отличие от некоторых реализаций GCC/Clang. Поэтому результаты вычислений могут немного отличаться в зависимости от компилятора и платформы.
